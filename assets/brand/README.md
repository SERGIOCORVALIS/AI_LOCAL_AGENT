# Brand — Local AI Agent

Official avatar / logo for the local AI agent.

| File | Use |
|---|---|
| `local-ai-agent.png` | Source logo (README, docs, GitHub) |
| `apps/api/admin/brand.png` | Served at `/admin/static/brand.png` (admin UI favicon, rail, chat, FAB) |

## Telegram bot photo

Bot profile pictures are set in Telegram (not via our API):

1. Open [@BotFather](https://t.me/BotFather)
2. `/mybots` → your bot → **Edit Bot** → **Edit Botpic**
3. Upload `assets/brand/local-ai-agent.png`

## GitHub

After push, the README hero image uses this file. Optional: set the same PNG as the repository social preview in GitHub → Settings → General → Social preview.
